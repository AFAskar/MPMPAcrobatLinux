## Explicit Disclosures & Boundaries

1. **No runtime script overrides (removed 2026-11-22 in `33f6cb4`/`0e19a42`)**: Original embedded PDF scripts execute verbatim. Upstream 2024 `v24.2.0+261023` `ApplyWildshape` (`pop.wildshapeShow` typo) throws the same `ReferenceError` in both engines; 2014 `v14.2.0+261023` has no such bug and passes Moon Druid Wild Shape Wolf cleanly in both engines.
2. **Upstream `v24.2.0+261023` `format2()` bug & subclass/UA warnings (unpatched)**: 2024 `format2()` plain-string `countDecimals()` `TypeError`, 2024 `bard-college of swords` 8 warnings, and 2014 `wizard-theurgy-ua` 20 console messages remain unmodified upstream behavior.
3. **Trusted-input & synchronous execution boundary (Finding 15)**: `mpmb-reader` is strictly for trusted local MPMB fixtures and user-approved add-ons (`docs/native-reader.md`). Document scripts can pass local paths to the file bridge without an interactive picker, and QuickJS runs synchronously in the UI process without an execution-time interrupt (memory/stack limits and bounded `read_bounded_file` import caps apply).
4. **Acrobat-Pro-only APIs unreachable in Reader**: `MPMBImportPage`, `tDoc.exportAsXFDF` file write (MPMB uses `exportAsXFDFStr`), `tDoc.importAnFDF`, authoring `Template.hidden`/`extractPages`/`createTemplate`, and multi-document `app.openDoc` scripting remain outside Reader scope.
5. **Cosmetic & environment nuances**: Pixel-level font/line-wrap metrics, occasional native leading `+` formatting differences on numeric attack headers, non-commit live keystroke filtering in GUI, Phase 2 `toolbar24` Reader-VM differences (`app.calculate` resets to `true` on cold Reader reopen; idle Windows VM `app.monitors.primary()` threw `GeneralError`), and Win32 `"ASK USER DIALOG"` radio-group auto-focus of `r000` on `OK` in 2014 race selection.
