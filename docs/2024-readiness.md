## Explicit Disclosures & Remaining Scope

1. **No runtime script overrides (removed 2026-11-22 in `33f6cb4`/`0e19a42`)**: The former `mpmb-2024-261023-wildshape-pop-typo` runtime repair was explicitly removed at the user's request so the native runtime executes the original embedded PDF scripts identically to Adobe Acrobat Reader. Upstream 2024 `v24.2.0+261023` `ApplyWildshape` (`pop.wildshapeShow` typo) throws the same upstream `ReferenceError` in both engines (`output/testing/native-2024-classes-1795345258415621059/classes-2024.json`); 2014 `v14.2.0+261023` has no such bug and passes Moon Druid Wild Shape Wolf cleanly in both engines.
2. **Upstream `v24.2.0+261023` `format2()` bug (not patched)**: In the paid 2024 PDF, `format2()` checks `if (isNaN(newValue))` before converting to `Number`, leaving plain numeric strings (e.g. `"1"` on `Carrying Capacity Multiplier` during `ResetAll(true)` / `DirectImport(true)` or `"2"` from Goliath Powerful Build) as `String` so `newValue.countDecimals()` throws `TypeError` in both engines. Isolated and verified explicitly in `verify-2024-toolbar-workflows.py`; no runtime patch added.
3. **Upstream subclass/UA warnings (not patched)**: 2024 `bard-college of swords` emits the same 8 original warnings in both Native and Real Reader (selected-style cold reopen is clean); 2014 `wizard-theurgy-ua` emits 20 original console messages about Forge/Grave/Order/Twilight Domain choice names with `execution_passed: true` and `diagnostic_errors: []`.
4. **Acrobat-Pro-only APIs unreachable in Reader**: `MPMBImportPage`, `tDoc.exportAsXFDF` file write (MPMB uses its genuine `exportAsXFDFStr` XML fallback dialog), `tDoc.importAnFDF`, authoring `Template.hidden`/`extractPages`/`createTemplate`, and multi-document `app.openDoc` scripting remain outside Reader scope.
5. **Cosmetic & environment nuances**: Pixel-level font/line-wrap metrics, occasional native leading `+` formatting differences on numeric attack headers, non-commit live keystroke filtering in GUI, Phase 2 `toolbar24` Reader-VM differences (`app.calculate` resets to `true` on cold Reader reopen; idle Windows VM `app.monitors.primary()` threw `GeneralError` in Phase 2 while passing in Phase 1), and Win32 `"ASK USER DIALOG"` radio-group auto-focus of `r000` on `OK` in 2014 race selection (recorded in `tools/native/profiles_2014.py`).
